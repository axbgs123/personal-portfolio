标题
保姆级｜把文字变成专业流程图

详情
做方案时，我最不想碰的往往是流程图。内容已经有了，耗时间的是挪方框、拉连线，修改一个节点后又要重新排版。

这次我把 Diagram Design 从安装到导出完整跑了一遍。它可以安装到 Codex 或 WorkBuddy 里，支持流程图、泳道图、鱼骨图、甘特图和四象限等39种图形。生成的 HTML 和内联 SVG 仍然可以修改。

案例材料：一段35分钟的产品周会记录。
① 后端处理支付回调重复入账。
② 测试补12条支付回归用例。
③ 产品确定老用户补偿方案。
④ 运营更新版本上线公告。

生成的流程图列出了4项待办、负责人和截止时间。第3项的两个字段为空，图中用橙色标出，并连接到回查23:18逐字稿的分支。补齐信息后，流程返回检查节点。

安装时，在 Codex 或 WorkBuddy 里粘贴这段话。

“请安装 GitHub 上的 Diagram Design Skill，项目名称是 cathrynlavery/diagram-design。请阅读 README 和 SKILL.md，安装到全局 Skill 目录，并检查依赖和加载状态。”

使用时先粘贴材料，再说明图形、比例和文件格式。如果还不确定该用哪种图，可以让 Skill 先给出选择和理由，确认后再生成。
