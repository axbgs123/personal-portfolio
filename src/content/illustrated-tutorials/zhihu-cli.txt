推荐标题

保姆级｜让 Agent 帮你搜知乎、找收藏

发布详情

知乎推出了官方 CLI Skill。装进支持 Skill 的 Agent 工具后，可以直接搜索知乎内容、读取热榜、调用知乎直答；完成账号授权后，还能整理自己的作品、关注和近期收藏。

这次不只做安装演示，我用官方 CLI 把授权、搜索、热榜、直答和近期收藏都真实跑了一遍。小白可以按顺序操作：

1. 准备电脑、Agent 工具和知乎账号；
2. 从知乎官方地址安装 zhihu-cli Skill；
3. 登录开放平台，在个人中心申请 Access Secret；
4. 把密钥交给 Agent，验证授权状态；
5. 分别测试搜索、热榜、知乎直答和近期收藏；
6. 根据最后一页的排错表检查常见问题。

安装时直接复制：

请下载安装 zhihu-cli Skill 并完成初始化配置：
https://developer-cdn.zhihu.com/zhihu-cli/releases/stable/skill/zhihu-cli-skill.zip

完成授权后，先试公开搜索：

“请搜索知乎上‘普通人转行 AI 的真实路径’，返回 3 条；保留标题、作者、正文摘要和原文链接。”

这次前三条搜索结果都夹带了课程导流。也就是说，CLI 能帮你把资料和链接找回来，但不能替你判断可信度。第二轮可以继续要求它剔除“加微信、领资料、体验课、报名入口”，只保留写清原职业、学习周期、作品或求职结果的内容。

近期收藏也做了真实测试：我先在知乎收藏了 3 条与 AI 工作流有关的公开内容，再让 Agent 读取最近 3 条。CLI 返回了标题、作者、摘要、收藏夹和原文链接，顺序与网页端一致。后续可以继续要求它按主题归类，但整理出的观点仍要回到原文核对。

Access Secret 只展示一次，不要发群、不要出现在截图或公开文档里。官方 Skill 会优先把密钥保存到系统密钥链。搜索、热榜和直答的试用额度不同，最终以开放平台个人中心实时显示为准。
