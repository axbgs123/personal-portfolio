# 仓库与案例展示二次整理

## 任务与边界

对象是陈祉辰的真实产品与视觉交付案例；浏览者需要先辨认作品，再阅读方法或播放成片。不增加随机探索、工具式检视或虚构截图。保留主项目、原网站、联系信息与未涉及的内容。

按用户要求移除创亿鸭的“角色职业延展”和“文创风格定制工作流”：同时移除对应目录、介绍、数据和公开素材，源目录不动。保留三条 AI 漫剧及原有主题策划/交付说明。

## 设计计划

- 色板：纸白 #f6f6f6、墨黑 #090909、灰 #686868、冷蓝 #315be8、深蓝 #2649bd、浅蓝 #e8edff；深底蓝色文字为 #9cb7ff。蓝色取代旧朱红点缀，限定在当前内容、行动入口和局部底板，不铺满全页。
- 字体：Haas 展示与标题，苹方中文正文，等宽字体仅用于阶段、片名编号等实义标注。
- 更多项目：连续项目索引配固定比例大预览窗。每条索引有真实缩略图/流程、完整标题与直达详情链接；预览切换不构成访问门槛。
- 短剧：片单与成片形成紧凑放映区，原素材独立收纳；视频原比例、有真实视频帧封面、按需播放。
- 英语面试：以一次练习的实际链路作为核心图示，产品判断双栏，能力图与 PRD 保持可读宽度，演示入口可直接点击。
- AIGC：错位完整展墙与作品展签，去除放大检验、拖拽与滑杆，原图和应用案例都直接可达。

对方案的自检：不把每个分类换皮成相同卡片，也不靠无关小游戏制造互动。每种排布服务不同内容；移动端、键盘和减少动态效果偏好都要可用。

## 落地与校验

- 仅创亿鸭删减两组：原 19 条现为 3 条视频；全迁移数据现有 90 条记录、28 次图片引用、10 条视频、34 份独立原始媒体。两组的 16 张公开图片移入 `/Users/baiyan1/.Trash/cz-removed-ip-sections.TQI2Z5`，可恢复；用户提供的旧网站目录没有修改。
- 导入脚本同步表达删减规则，重新静态提取与现有 JSON 精确比较通过，保留媒体 SHA256 与原件一致。不会再次导入用户已删除章节。
- 10 张视频封面由 `prepare-migrated-posters.mjs` 在原片第 2 秒直接抽帧，不生成或替换影片。所有视频 `preload="none"`，只有用户操作才播放。
- 浏览器实测：更多项目 5 个索引/封面切换/详情直达；英语流程目录定位到导航栏下方；AIGC 无检验、平移或缩放控件；1280px 与 390px 下无横向溢出或失效图片。
- 真人短剧实测：播放二十二集会暂停二十一集；播放原素材会暂停成片；收起原素材后全部暂停。目录在手机端定位约 92px，低于 76px 导航栏。
- 创亿鸭放映墙优先于制作说明；三条影片都保留原比例，职业延展和风格定制在正文、索引、目录与公开图片中均不存在。
- 已提供的两个 HTTP 原演示地址可从页首按钮、导语和正文点击；未宣称外部服务当前可用。未知在线地址未捏造。
- 全套 262 项测试通过；新增/修改展示组件及测试 lint 通过，生产构建保留原有无关 Hook/console 警告。本轮没有 GitHub 推送或公开部署。
- 最终生产构建 71/71 页成功，预览脚本指向 `.next-archive-refinement-final` 并运行在 3003。首页、仓库、四个迁移详情、AIGC、教程与文章入口全部返回 200；已移除图片的原公开地址返回 404。视频帧封面合计约 346 KiB，不增加原片预加载。
