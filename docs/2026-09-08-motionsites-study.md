# MotionSites 作品参考：作品放映台

本次仅研究站内作品的公开预览，不参考 MotionSites 自身的导航与商品列表，不领取需要账号授权的提示词，不复制作品资产。

## 观察

- [3D Jack Portfolio](https://motionsites.org/prompts/3d-jack-portfolio-hero)：公开预览中人物与大字叠置，身份不再是两块分离的内容。
- [Form Study](https://motionsites.org/prompts/form-study)：实际播放预览，观察到居中的动态形体、角落的作品计数与缩略索引。借鉴主视觉与索引的主次关系，不复制彩色折射材质或其文案。
- Reading Library 只查看了公开说明，不据此声称已验证其完整交互。

## 实现前计划与自审

主体：陈祉辰的 AI 产品作品集；访客任务：理解两个真实产品案例并进入详情。
色板：纸白 #f6f6f6，墨黑 #090909，说明灰 #686868，朱红 #d74436，深朱红 #b83228，浅朱红 #f6e5e2。没有新增颜色。
字体：展示沿用 Portfolio Haas，中文正文苹方，作品序号用现有等宽字体。

布局比较：继续两块图文堆叠 → 节奏重复；全屏自动轮播 → 抢走阅读控制；最终采用主动选择的作品放映台。

自审：不让动效取代内容。去掉自动轮播、鼠标劫持和随机选作品；按钮可用键盘操作，未选作品仍有清楚标题，完整案例是原生链接。仅一个主要展示装置，不改所有分类为相同交互。图像明确标注为概念封面，真实界面仍在详情页。

动效：项目切换采用短促横向揭幕，文字轻微错峰；进入视口时镜框从窄幅展开。减少动态模式下立即展示，不隐藏阅读内容。没有新 WebGL、视频或依赖。

## 浏览器自审修订

实际测试发现底部索引被点击时，舞台标题可能已滚出视口。因此将两个项目选择按钮移到舞台上方，点击时直接看见封面与标题变化；保持原生滚动，不用强制滚回顶部补救。
