# 分类浏览装置 · V2 接入

## 范围与设计约束

仅修改 `giats-portfolio-chenzhichen-v2`。原站、第一版重设计目录、3002 的旧构建均保持不动。3003 用独立新构建预览，不部署到公网，不上传或删除资料。

本轮用户明确要求：档案机只用于「文字与思考」，其他仓库类目各有不同的新颖展示。外层扇形入口保留；详情正文和原始资源不重写。无真实文件的分类不虚构作品、照片、执行能力或视频。

设计沿用 frontend-design：每类用一种与内容有关的真实操作，而非把同一卡片墙换名称。大面保持黑白灰，仅在动作箭头、状态、进度和焦点细节引入获认可的朱红。

- 纸面 `#F6F6F6`，墨色 `#090909`，辅助字 `#686868`，线条 `#CDCDCD`。
- 朱红符号 `#D74436`；浅底小字 `#B83228`，深底小字 `#EF7768`，分别验证对比度。
- 保留现有 Portfolio Haas / 苹方正文与等宽操作标注。
- 不把历史 `--portfolio-acid` 改成红色，避免大块既有灰色表面一起变红。
- 首页构图、像素肖像、开场、猫、音乐功能保持，状态色作小范围统一。

## 交互底线

- 原生链接首次激活直达，不把点击强制变成二次选择。
- 机械操作有按钮、方向键或原生范围输入替代。
- 写作恢复队列、纸签、搜索词与搜索状态；工具和图文按稳定 slug 恢复检索现场。
- 支持减少动态效果；不新加音频、WebGL、持续动画循环或依赖包。
- 横向胶片不吞竖向页面滚动；鼠标拖片与点击打开相区分。

## 第二次反馈：避免重复与照搬

用户指出摄影胶片与图文胶片、教程资料匣与 Skill 工具匣形式重复。随后明确拒绝“盲选一课”“随机取出 Skill”等把文章抽取复制到其他内容的方案。取消这些方案，不增加随机功能。

本轮调整为：摄影使用暗房取景窗，交互用于构图比例、系列选择和灯面亮度；教程总入口使用四向资料路由台，用户明确选择目标，四个真实入口始终直达。图文胶片和 Skill 手动取出／归位保持，学习路径与方法步骤不得凭空编造。
