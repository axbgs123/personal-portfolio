# 字由：独立实时排版小样

> 已暂停：用户指出此方向偏离“内容展示方式”。页面源码已移至 `docs/experiments/type-play/paused-page.jsx`，不再注册 `/type-play` 路由，也不再使用独立站点外壳。原实验组件和记录仅供恢复，不接入正式仓库。

## 范围

用户确认了“把一句话玩成黑白海报”的小样。新增 `/type-play`，不替换首页、仓库或任何内容类目；不改最初版本。这里是本地实时排版，不是 AI 生图，也不发送输入内容。

## 构图计划（实施前）

- 纸面 `#f6f6f6`、字墨 `#090909`、工作台 `#e8e8e8`、边线 `#cdcdcd`、辅助字 `#686868`、操作点 `#b83228`。导出的海报只有黑白灰，朱红只用于当前操作状态。
- 展示字：粗黑中文系统字体及现有 Portfolio Haas；正文：苹方/微软雅黑；控制标注：SFMono。表达重点是访客写下的文字，不再做一段巨大的营销标题。
- 桌面为一个大画布与一条安静的侧边工具带；手机画布先出现，工具在下方。控制不覆盖作品，不另加滚动装置、猫、转场或自动播放。

```text
ZC / 字由                         返回网站
┌─────────────────────────┬──────────┐
│                         │ 一句话   │
│     可直接拉动的字        │ [输入]   │
│     ↖ 连带 → 碰撞         │ 连接 / 下落│
│                         │ 定格 / 保存│
└─────────────────────────┴──────────┘
```

签名交互只有一个：整字物理拉扯。拖拽速度和方向影响结果，邻字会被牵引，松手保留惯性，访客可以真正得到自己的海报。重排只是复位；没有随机内容、盲选或固定几种构图冒充生成。

自审：不采用“新名字的内容卡片”或黑底按钮仪表盘。纸面本身就是首屏；去掉不产生可见结果的装饰控制。冻结和恢复有明确反馈，导出复用同一绘制函数。

## 验收目标

- 整字拖动、边界碰撞、连带与松手惯性真实；鼠标、触屏、键盘均可调构图。
- 输入按字素计数，不破坏组合字符；不执行输入中的 HTML。
- 定格后画面稳定，PNG 与当前构图、反色一致；下载失败有可操作提示。
- 无交互静止时停止 RAF，后台不持续计算，减少动态效果偏好默认定格。
- 现有正常页面不进入独立布局，不改变原站文件或活动生产构建。
